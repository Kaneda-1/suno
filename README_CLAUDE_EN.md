## 🏗️ Tag Structure

### Primary Tags
| Tag | Function | Common Modifiers |
|-----|---------|----------------------|
| `[Intro]` | Instrumental opening | Long, Short, Mellow, Exciting, Dreamy |
| `[Verse]` | Main stanza | Whispered, Angry, Mysterious, Spoken, Intimate |
| `[Chorus]` | Main refrain | Ensemble, Whispered, Eerie, Slow, Energetic |
| `[Bridge]` | Musical bridge | Instrumental, Vocal, Emotional, Transitional |
| `[Outro]` | Closing section | Fading, Urgent, Mournful, Lingering |

### Secondary Tags
| Tag | Function | Best Use |
|-----|---------|-----------|
| `[Pre-Chorus]` | Preparation for chorus | Once, before the first chorus |
| `[Hook]` | Catchy hook | Rap/Hip-Hop, Pop |
| `[Interlude]` | Instrumental break | Changing mood or energy |
| `[Break]` | Brief pause | Between verse and chorus |
| `[Build]` | Tension buildup | Before drops or choruses |
| `[Solo]` | Instrumental solo | Specify instrument (e.g., `[Saxophone Solo]`) |

## 🔧 Troubleshooting

**🚫 System ignores my modifiers**
- ✅ Use concrete modifiers (Angry, Slow, Whispered)
- ✅ Avoid vague ones (Good, Nice, Beautiful)
- ✅ Combine a maximum of 2-3 modifiers per tag

**🚫 Transitions don't work**
- ✅ Use `[Break]` between conflicting sections
- ✅ Add transition effects: `*fade in*`, `*build up*`
- ✅ Specify instruments during transitions

**🚫 Style isn't respected**
- ✅ Put the primary genre first
- ✅ Use specific genres instead of generic terms
- ✅ Limit to 5-7 elements in the Style Prompt
